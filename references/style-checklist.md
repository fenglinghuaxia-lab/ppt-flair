# 风格清单 & 配方（Style Checklist & Recipes）

本文件用于高层汇报视觉设计过程中的快速决策。按场景查找，避免每次重新拍脑袋。

## 1. 标题选择清单（Stage A 决策表）

| 场合 | 推荐书风 | 笔触密度 | 情绪 |
|------|---------|---------|------|
| 年度大会主视觉 | 行楷/大字榜书 | 中-高 | 磅礴、向上 |
| 总经理汇报封面 | 行书 | 中 | 沉稳、权威 |
| 战略发布 | 草书（慎用，需可读性测试） | 高 | 突破、张力 |
| 内部表彰/总结 | 楷书 | 低-中 | 端正、温暖 |

**检验规则**：标题字体生成后，缩至封面实际尺寸的 20% 检查可读性；看不清则降一档笔触密度。

## 2. 底图筛选评分表（Stage B）

| 维度 | 权重 | 达标标准 |
|------|------|---------|
| 氛围匹配 | 30% | 与标题情绪同频（如"突破"→攀登/破浪） |
| 构图干净 | 25% | 主体不在标题区；留白 ≥ 30% |
| 对比度 | 25% | 明暗分层明显，可压暗出层次 |
| 低噪点 | 20% | 无人群、文字、杂乱纹理干扰 |

**总分 ≥ 80 才入选**，否则换图。隐喻意象优先级：攀登 > 航行 > 云海 > 远山 > 城市。

## 3. 蒙版配方（Stage D）

### 实测定稿配方（2026-08，用户三轮微调确认，优先复用）

| 参数 | 值 | 说明 |
|------|-----|------|
| 饱和度 | 0.92 | 保留底图原色，不做重度降饱和 |
| 对比度 | 1.06 | 轻度增强 |
| 蓝色叠加 | RGB(16,30,54)，blend 0.22 | 轻度统一色调，**不压死底色** |
| 整体亮度 | 0.97 | 略暗于原图，突出白色标题 |
| 底部压暗 | 画面 72% 以下线性渐变，最大 α≈80 | 给署名/日期区留位 |
| 暗角 | 极轻（椭圆蒙版 + 180px 高斯） | 只收边缘，不动中心 |
| 装饰线/饰点 | **无** | 用户明确否掉，画面只留底图+标题 |

**教训**：调色宁轻勿重——重度降饱和 + 强乘法压底会被否（"色调太暗，看不出底色"）；但完全不压又不够突出文字。0.22 叠加 + 0.97 亮度是验证过的平衡点。

### 颜色叠加层（其他基调备选）
| 底色基调 | 叠加色 | 透明度范围 |
|---------|--------|-----------|
| 深蓝黑 | 冷蓝灰 #2B3A55 | 15%-30% |
| 深蓝黑 | 暖金 #8C6F3F | 20%-35% |
| 深黑 | 冷灰 #3A3A3A | 10%-25% |
| 深黑 | 赭石 #7A4E2D | 15%-30% |

### 渐变蒙版（保证标题可读）
- 标题区压暗：径向/线性渐变，标题位透明度 60%-80%，画面边缘 0%-20%。
- 禁止全图统一压暗超过 50%（会失去层次感）。

### 模糊与高光
- 边缘高斯模糊 8-20px，用于底图与底色衔接生硬时。
- 高光只加一处（对角或顶部），面积不超过画面 10%。

## 4. 配色参考（深色系）

| 角色 | 色值 | 用途 |
|------|------|------|
| 主底 | #0B1220 ~ #101A2E | 全尺寸底色矩形 |
| 辅助底 | #16233A | 内容卡片、分区 |
| 标题白 | #FFFFFF / #F5F0E8 | 书法字主体 |
| 点缀金 | #C9A86A | 装饰线、小标签 |
| 点缀冷蓝 | #7FA6C9 | 数据强调 |
| 警示红（慎用） | #B4432E | 仅限关键警示，面积 < 5% |

**禁用**：荧光绿、电光蓝、玫红、亮紫等霓虹色系。

## 5. 构图规则

- **标题位（实测定稿）**：水平居中，垂直中心在画面 **40% 高度（中线以上）**——用户明确否掉中线以下位置；放大版可用 38%。
- **标题尺寸**：宽约画面 60%（基准）/ 68%（强调），AI 书法透明 PNG 按此宽度等比缩放。
- 留白：标题四周至少保留 15% 画面宽度无干扰元素。
- 不对称构图必须"刻意"——要么大留白对冲，要么元素有明确视觉引导线。
- 单焦点原则：全图只有一个视觉主体（通常=标题），其余都是氛围。

## 6. 交付前自检清单（Stage E 收尾）

- [ ] 3 米外标题可读
- [ ] 无霓虹/过亮色块
- [ ] 画面只有一个视觉焦点
- [ ] 书法字与背景对比充足（无"打架"）
- [ ] 书法字每个字形正确（AI 生图必须人工核对，有错字重生成）
- [ ] 蒙版参数已记录（供同系列复用）
- [ ] 已测试 ≥ 2 个变体并说明取舍
- [ ] 最终交付：多候选用 PNG 文件逐一交付（或 HTML 画廊预览 + PNG 附路径）

## 7. 提示词模板（给生图工具的起点）

### 书法标题（黑底白墨 → 亮度抠图）

```
中国传统书法：四个白色大字「XXXX」，用浓墨行楷写在纯黑色背景上。
笔画遒劲有力，笔锋锐利，带飞白枯笔质感和少量墨点飞溅，
字字清晰、字形准确，横排居中构图，高对比，无其他文字无水印。
```

现代锐利风替换句："笔画锋利果断、棱角分明，如刀劈斧凿，带速度感和飞白"。

### 底图（大气恢弘方向——实测被认可）

```
史诗级航拍视角：无垠云海之上，远处连绵雪山被初升的太阳镶上金边，
云海壮阔翻涌，气势磅礴，天空占画面大面积、霞光四射，
深蓝与暖金交融，大气恢弘，电影级光效，
画面下部保留较平稳的暗部留白，适合高端商务汇报封面背景，无文字无水印。
```

**反面教训（会被否）**："深蓝黑色夜空、一线冷光、极暗"类压抑暗调提示词——用户评价"过度压抑，缺少大气的感觉"。要大气：光占大面积、暖金主光、尺度拉开、恢弘/史诗级等词。

其他通过验证的意象方向：光柱穿云（多束光柱从云缝洒落）、山脉晨雾（云雾如河流在山谷间流动）。

### 交付画廊（HTML，多候选预览）

用 Python 把候选 PNG 转 base64 内嵌进 HTML 画廊页，一屏看全，避免预览面板逐张显示造成"未合成"误解。脚本见 `scripts/build_gallery.py`。

## 8. 工具链脚本（scripts/）

| 脚本 | 用途 | 用法 |
|------|------|------|
| `keyout_title.py` | AI 书法黑底白字 → 透明 PNG | `python keyout_title.py <input.png> <output.png>` |
| `compose_cover.py` | 底图调色 + 标题合成，全参数可调 | `python compose_cover.py --bg 底图.png --title 标题.png --out 成品.png` |
| `build_gallery.py` | 多张 PNG → HTML 画廊（base64 内嵌） | `python build_gallery.py 输出.html 图1.png "标签1" 图2.png "标签2"` |

依赖：Pillow（`pip install Pillow`），运行加 `-X utf8`（Windows 中文路径）。
