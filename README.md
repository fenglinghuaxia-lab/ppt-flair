# ppt-flair · 高层汇报视觉风格 Skill

> 书法字 + 气质底图 + 蒙版校色 —— 高管级演示视觉的可复用风格系统。

`ppt-flair` 是一个 WorkBuddy Skill，把"高层汇报 / 大会视觉封面"的设计流程固化为五阶段可执行工作流，内置风格规则、决策清单与真实案例基准。

## 安装

将本仓库内容放入 WorkBuddy 的 skills 目录：

- 用户级（个人所有项目可用）：`~/.workbuddy/skills/ppt-flair/`
- 项目级（团队共享，随仓库分发）：`.workbuddy/skills/ppt-flair/`

或直接解压 release 中的 `ppt-flair.zip` 到上述任一目录。

## 工作流（五阶段）

| 阶段 | 内容 | 产出 |
|------|------|------|
| A 字体概念 | 即梦生成书法字标题，导出透明 PNG | 2-3 个候选标题 |
| B 底图筛选 | 花瓣检索，四维评分（氛围/构图/对比/噪点）≥80 | 3-5 张候选 |
| C 底图精修 | 海螺P图 / Photoshop 裁剪调色合成 | 1 张精修主图 |
| D 背景系统 | 深色底色 + 蒙版叠加 + 渐变压暗 + 高光 | 背景合成图 + 参数 |
| E 精调循环 | 位置/尺寸/透明度迭代，2-3 变体测试 | 定稿封面 + 参数备忘 |


## 风格内核

- 深蓝黑底 + 低饱和暖/冷色叠加，禁霓虹色
- 书法大字标题，白色，透明 PNG，有意图感
- 单视觉焦点，留白 ≥15%，强对比电影感
- 铁律：定稿前测试 2-3 个变体
